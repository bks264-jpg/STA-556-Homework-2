Dataset

The Palmer Penguins dataset contains 344 observations and 8 variables, including penguin species, island, bill measurements, flipper length, body mass, sex, and year. After removing observations with missing measurements, 342 penguins remained for the analysis.

The dataset includes three penguin species (Adelie, Chinstrap, and Gentoo) sampled from three islands (Biscoe, Dream, and Torgersen) near Palmer Station, Antarctica.

Data Source: [Palmer Penguins Dataset](https://github.com/allisonhorst/palmerpenguins)


Project Purpose

The purpose of this project is to analyze the Palmer Penguins dataset to examine differences in average body mass among penguin species and how species distribution varies across islands. This project also demonstrates how Python can be used to clean, summarize, and visualize data to identify patterns and relationships.


How to Run the Analysis

- Download or clone this GitHub repository.
- Install the required Python libraries: pandas, matplotlib, and seaborn.
- Open notebooks/homework2.ipynb in Jupyter Notebook.
- Run the notebook cells in order to reproduce the analysis and figures.


Main Findings

Gentoo penguins had the highest average body mass (5,076.02 g), while Adelie (3,700.66 g) and Chinstrap (3,733.09 g) penguins had similar average body masses.

Penguin species were also distributed differently across islands. Adelie penguins were recorded on all three islands, while Gentoo penguins were only recorded on Biscoe Island and Chinstrap penguins were only recorded on Dream Island.

Overall, the results show differences in body mass among penguin species and an association between penguin species and the islands where they were sampled.
